# Core Harness Layer (`core/`)

The `core/` directory contains the foundational policy shared across all domain profiles in `ajackti-agent-harness`.

## Components

- [policy.json](policy.json): Declarative JSON definition of the external-first worker/reviewer policy (`execution_model.worker_cli` is the legacy `agy` binary/default while `execution_model.workflow_selection` chooses `WORKFLOW_WORKER=agy|devin`, default `agy`, and `WORKFLOW_CONTEXT=lean|compact|full`, default `lean`, with `reviewer_worker: "agy"` and `opencode_role: "probe_only"`), the coordinator-owned `model_selection` contract (`AGY_MODEL` allowed `claude-opus-5-5-high` and `gemini-4-argon-high`, preferred Opus while available, unset/empty defaulting to Gemini, `agy --print /usage` quota refresh, `--effort high`, `request-review`), `worker_validation` (`applies_to: "agy_workers_and_all_reviewers"`), `devin_worker_validation` (`swe-1-6-slow` tool-free generator, `ATIF-v1.7`, CLI `auto` / proof `Normal`, isolated cwd, `deny_all` + `PreToolUse` exit `2`, `0` tool calls/observations, fresh sessions, `devin_lean_only` per-session `disabled_tools` and `agent.tool_definitions` nonempty unique subset of `mcp_call_tool`, `mcp_list_servers`, `mcp_list_tools`, `mcp_read_resource`, `skill` blocking invalid definitions before apply while schema hiding is not authorization, strict JSON replacements mechanically applied with precondition hashes and atomic rollback, separate `usage_totals.devin` vs `usage_totals.gemini`), the `jev-1.13.0` pipeline, the `--max-reworks 2` ceiling and shared task-wide `retry_policy` ledger (across internal reworks and cross-run/model/worker/context restarts, never reset), protected boundaries, and routing rules for `antigravity-task-runner` vs `antigravity-sol-quant-runner` (`quant` stays `BLOCKED`; distinct worker/reviewer model names do not prove stronger review). [../scripts/model_policy.py](../scripts/model_policy.py) and [../scripts/workflow_policy.py](../scripts/workflow_policy.py) validate these contracts offline only; they perform no live Devin generation, benchmarking, quota fetching, or automatic failover.
- [AGENTS.template.md](AGENTS.template.md): Concise `AGENTS.md` template for copying into consumer repositories. Unfilled placeholders are explicitly marked with `<UNRESOLVED:...>`.

## Composition Model

1. **Core Policy ([policy.json](policy.json))**: Invariant across all domains; no profile or consumer repository may add unsupported workers/models/contexts, lower `agy` effort/permission mode, claim `high`/`request-review` or fabricated `agy` proof for Devin, weaken Devin `lean` `agent.tool_definitions` checks, disable `--no-resume-worker` or `--context-mode`, bypass `jev-1.13.0`, or reset the shared retry ledger. `compact`/`lean` prompts trim boilerplate only (preserving verbatim contract and full scoped source); optional RTK filtering applies only to passing supported `pytest` logs with equal raw/filtered pass counts (`unittest` unchanged). Consult the installed `using-superpowers` skill (`$HOME/.codex/plugins/cache/openai-curated-remote/superpowers/7.0.1/skills/using-superpowers/SKILL.md`; external-first overrides local/Solo defaults) and prefer official Microsoft Playwright MCP for relevant browser/UI work.
2. **Domain Profile (`<domain>/profile.json`)**: Adds tool requirements (`tools`), candidate verification commands (`candidate_checks` in `example_unverified` status), expected evidence (`expected_evidence`), and domain-specific risks (`special_risks`).
3. **Repo Context ([../templates/repo-context.json](../templates/repo-context.json))**: Owned by the consumer repository; defines `workdir`, the list of owner-accepted verification commands (`accepted_verify_cmds`), and the allowed file scope (`scope`).
